# Ru-max для Joomla

Joomla-версия WP Ru-max 1.0.2. Папка подготовлена как самостоятельная ветка расширения Joomla и не изменяет исходники WordPress.

## Что загрузить в ветку `joomla.max-wp`

Загрузите в корень ветки всё содержимое папки `joomla-ru-max-main`:

- `extensions/` — исходники компонента, плагинов и модуля;
- `packages/` — готовые ZIP-файлы отдельных расширений;
- `pkg_rumax.xml` — манифест общего пакета;
- `build-package.sh` — пересборка установочного архива;
- `rumax-joomla-1.0.2.zip` — готовый архив для установки;
- `plugin-page.html` — HTML страницы загрузки для Joomla;
- `rumax-page.css` — отдельные стили страницы для `user.css` шаблона Cassiopeia;
- `SEO.md` — готовые SEO-поля, ключи, canonical, Open Graph и схема ссылок;
- `README.md` — инструкция по установке и настройке.

Старые архивы версий 1.0.1 и 1.0.61 удалены. Папку `wp-ru-max-main` в этот перенос добавлять не нужно.

Пакеты можно пересобрать командой `./build-package.sh`. После этого используйте только `rumax-joomla-1.0.2.zip`.

## Рекомендуемое размещение на GitHub

Используйте существующий репозиторий:

```text
https://github.com/RuCoder-sudo/wp-ru-max
```

Для Joomla создайте в нём отдельную ветку:

```text
joomla.max-wp
```

Новый репозиторий создавать не нужно: WordPress и Joomla-версии относятся к одному продукту Ru-max, а отдельная ветка не смешивает их исходники. Ветка `joomla.max-wp` пока не создана — сейчас в репозитории доступны `main` и `gh-pages`.

### Порядок загрузки

1. Откройте репозиторий `RuCoder-sudo/wp-ru-max` на GitHub.
2. Создайте новую ветку `joomla.max-wp` от актуальной `main`.
3. Загрузите в корень ветки содержимое папки `joomla-ru-max-main`.
4. Не добавляйте папку `wp-ru-max-main` внутрь Joomla-ветки.
5. Проверьте, что файл `rumax-joomla-1.0.2.zip` лежит в корне ветки.
6. Сделайте commit с сообщением вроде `Add Joomla Ru-max 1.0.2`.
7. Откройте ссылку ветки и проверьте, что архив скачивается.

Кнопки страницы уже подготовлены для будущего адреса архива:

```text
https://github.com/RuCoder-sudo/wp-ru-max/raw/refs/heads/joomla.max-wp/rumax-joomla-1.0.2.zip
```

Не удаляйте `rumax-joomla-1.0.2.zip` до загрузки в GitHub: это не лишний файл, а готовый установочный архив, на который ведут кнопки скачивания. Файлы `plugin-page.html` и `rumax-page.css` нужны для оформления страницы Joomla; удаляйте их только после того, как HTML и CSS уже перенесены на сайт.

## Страница Joomla

Файл `plugin-page.html` содержит готовый фрагмент страницы без шапки и подвала сайта.

1. Откройте файл `media/templates/site/cassiopeia/css/user.css` в редакторе шаблона Cassiopeia. Важно: правильное имя файла — `user.css`, не `user.css.css`. Cassiopeia автоматически подключает именно `user.css`.
2. Добавьте в него всё содержимое файла `rumax-page.css` и сохраните файл.
3. Откройте материал Joomla в режиме **HTML / исходный код**.
4. Вставьте содержимое `plugin-page.html` целиком. В HTML нет ссылки на CSS: её не нужно добавлять, потому что Cassiopeia подключает `user.css` сама.
5. Сохраните материал, очистите кеш Joomla и проверьте страницу в режиме инкогнито.
6. Если сейчас существует файл `user.css.css`, переименуйте его в `user.css` или создайте новый `user.css` и вставьте CSS туда. После очистки кеша в исходном коде страницы должна появиться ссылка на `/media/templates/site/cassiopeia/css/user.css`.

Кнопки скачивания в текущей версии ведут на GitHub-архив в ветке `joomla.max-wp`. Ссылка начнёт работать после загрузки ветки и файла `rumax-joomla-1.0.2.zip`.

Пакет включает:

- `com_rumax` — настройки, очередь, история, API MAX, прямые сообщения и обработчики AJAX;
- `plg_system_rumax` — глобальные CSS/JS, плавающий MAX-виджет, очередь и mail-уведомления;
- `plg_content_rumax` — отправка материалов Joomla, кнопка «Поделиться в MAX» и настройки материала;
- `mod_rumax_widget` — размещение того же виджета через стандартный менеджер модулей Joomla;
- нужные визуальные ассеты: MAX-иконки, стили, JS, звуки и SVG.

## Требования

- Joomla 4, 5 или 6;
- PHP 7.4+ (рекомендуется PHP 8.1+);
- PHP cURL и JSON;
- доступ Joomla-сервера к `platform-api2.max.ru`, Telegram API и включенным социальным сетям.

## Установка

1. Запустите `./build-package.sh`.
2. В Joomla откройте **Система → Установка расширений**.
3. Загрузите файл `rumax-joomla-1.0.2.zip`.
4. Включите плагины **Ru-max — System** и **Ru-max — Content**.
5. При необходимости опубликуйте модуль **Ru-max Widget**; системный плагин может выводить виджет глобально сам.
6. Откройте компонент **Ru-max**, укажите токен MAX и ID чата/канала.

## Очередь

Очередь запускается небольшими порциями при посещении сайта. Для сайтов с отложенными публикациями рекомендуется cron:

```text
GET /index.php?option=com_rumax&task=cron&key=YOUR_CRON_KEY
```

Ключ задаётся на вкладке **Настройки → Ключ защищённого cron**. Для запуска cron без браузерной сессии можно использовать кнопку обработки очереди в админке или этот защищённый URL. Публичные AJAX-запросы виджета всегда проверяют CSRF-токен.

## Совместимость и безопасность

- исходная папка `wp-ru-max-main` не изменяется;
- токены не выводятся в журнал;
- AJAX сообщения и история требуют Joomla form token;
- значения из админки экранируются при выводе;
- таблицы имеют отдельные префиксные имена `#__rumax_*`;
- удаление расширения удаляет таблицы только через штатный uninstall SQL; сохранение данных можно изменить в настройках до удаления.

## Важно

API-поведение MAX и социальных сетей зависит от актуальных прав токена и форматов, которые принимает конкретный аккаунт. Перед рабочим запуском используйте «Проверить подключение», тестовую публикацию и проверьте журнал.
